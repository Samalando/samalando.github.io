Voxy Import commands

/voxy import world [world name]

Imports all chunks generated from a world

/voxy import bobby [world name]

Imports all chunks generated using bobby

/voxy import dh [/path/to/sqlite]

Imports all LoDs generated by Distant horizons. Requires this mod

/voxy import raw [/path/to/file]

Imports all chunks located in the provided raw file

/voxy import zip [/path/to/zip]

Imports all chunks found in the zip file. Must contain a region folder.

/voxy import cancel

Cancels current importing task.

Other Voxy Commands

/voxy reload

Reloads all Voxy chunks.
